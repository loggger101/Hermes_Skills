# ant-design-vue 4.2.6: the Vue port, and how its tokens line up with Ant Design v6

Source: [vueComponent/ant-design-vue](https://github.com/vueComponent/ant-design-vue) (21.7k stars, MIT; GitHub shows `NOASSERTION`; pushed 2026-10-05). The npm line is **4.2.6, published
2024-11-11**; the repository's other branches (`feat/vapor`, `cssinjs`, `feat/infra`, `feat/button`) are experiments and the latest GitHub release is also 4.2.6, so *the repo being
active does not mean a new release*. Peer: `vue >= 3.2.0`. Companion to `antd-v6-design-md-exemplar.md` (the React original). Not covered: a browser render, the docs site, the 1.x/2.x/3.x branches, Vapor.

## Weight and loading

- 22 runtime dependencies (`@ant-design/icons-vue`, `@ctrl/tinycolor`, `@emotion/hash`, `stylis`, `dayjs`, `lodash`, `lodash-es`, `async-validator`, `@simonwep/pickr`, ...), **85 MB** on disk, `main` is `lib/index.js` (CJS) and `module` `es/index.js`.
- Prebuilt: `dist/antd.min.js` **1,523 kB (421 kB gzip)**, `antd.esm.min.js` 1,498 kB, `antd-with-locales.min.js` 1,747 kB; the only stylesheet is `dist/reset.css` (1.3 kB gzip) because component CSS is generated by **cssinjs** at runtime.
  Import by component with a bundler (`sideEffects` is limited to `site/*`, `*.vue`, `*.md`, `dist/*`, `*.css`) rather than loading the bundle.
- `require('ant-design-vue')` exports **159 names, 139 of them components**. The first require after install took **46 s** (cold file cache for 85 MB of small files, most likely antivirus scanning); later requires took **1.8 to 2.3 s**, and
  `await import('ant-design-vue')` (ESM) worked in 1.7 s. Warm it before timing, and keep it out of serverless cold starts.

## Seed tokens: identical to antd v6's DESIGN.md

`theme.defaultSeed` (43 keys) printed: `colorPrimary #1677ff`, `colorSuccess #52c41a`, `colorWarning #faad14`, `colorError #ff4d4f`, `colorInfo #1677ff`, `fontSize 14`, `borderRadius 6`, `controlHeight 32`,
`sizeUnit 4`, `sizeStep 4`, `lineWidth 1`, `lineType solid`, `zIndexPopupBase 1000`, `motionUnit 0.1`, `wireframe false`, plus the easing curves
(`motionEaseOut cubic-bezier(0.215, 0.61, 0.355, 1)`, `motionEaseInOut cubic-bezier(0.645, 0.045, 0.355, 1)`, ...), the font stack starting `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto`, and 13 preset palettes (blue `#1677ff`, purple `#722ED1`,
cyan `#13C2C2`, green `#52C41A`, magenta/pink `#EB2F96`, red `#F5222D`, orange `#FA8C16`, yellow `#FADB14`, volcano `#FA541C`, geekblue `#2F54EB`, gold `#FAAD14`, lime `#A0D911`). These are the same numbers the React
v6 exemplar documents (14 px base, 6 px radius, 32 px controls, 4 px grid), so **a DESIGN.md written for antd v6 applies unchanged to ant-design-vue 4**; it is the same token system, in Vue components.
`theme` also exports `defaultAlgorithm`, `darkAlgorithm`, `compactAlgorithm`, `useToken`, `defaultConfig`.

## Theming through `ConfigProvider`

`h(ConfigProvider, { theme: { token: { colorPrimary: '#00b96b', borderRadius: 2 } } }, () => h(Button, { type: 'primary' }, ...))` changed the generated CSS (`#00b96b` and `border-radius: 2px` present in the extracted style,
and a different hashed class: `css-dev-only-do-not-override-s6hmb` versus `...-1p3hq3p`), so token overrides work per subtree, not globally by CSS variables. Algorithms are passed as `theme.algorithm`.

## SSR (Vue 3.5 `renderToString`)

- Button: `<button class="css-dev-only-do-not-override-1p3hq3p ant-btn ant-btn-primary" type="button"><span>Save</span></button>`; **under `NODE_ENV=production` the class becomes `css-1p3hq3p`** (the `dev-only-do-not-override` prefix is development-only, so do not hard-code selectors with it).
  Modifiers: `ant-btn-lg`, `ant-btn-loading`, `ant-btn-dangerous`. Input: `ant-input ant-input-sm css-1p3hq3p`. A one-column Table rendered 823 characters of plain `<table>` HTML with no ARIA roles; an open `Modal` rendered `role="dialog"` inline.
- **Styles are not in the HTML by default.** Extract them with the internal cssinjs helpers: `import { createCache, extractStyle, StyleProvider } from 'ant-design-vue/lib/_util/cssinjs'` (the `lib/` CJS path was the one run), wrap the app in
  `<StyleProvider :cache="cache">`, render, then `extractStyle(cache)` returns `<style data-vc-order="prependQueue" ... data-token-hash=...>` with rules such as `:where(.css-...) a{color:#1677ff;text-decoration:none;...}`. For one primary Button the extracted CSS was **27,034 characters**
  (global base rules plus button styles) and 27,975 with a custom token set: every page pays that, so extract once per render and de-duplicate across requests. The path is internal (`_util`), so pin the version.
- Dark algorithm: the same render with `theme.algorithm = theme.darkAlgorithm` produced a 27,974-character stylesheet; my regex for background colours matched nothing, so the dark values were **not** inspected.

## Choosing

For a Vue 3 back-office app that wants Ant Design's look this is the library; for Vue projects that care about bundle size or a modern release cadence note that npm has been at 4.2.6 since November 2024 and that antd (React) is on v6.
When writing a DESIGN.md or prompt for it, reuse the antd v6 exemplar and state the Vue specifics: `ConfigProvider` theming and cssinjs SSR extraction (the `h(ConfigProvider, ...)` render-function form was the one run).
