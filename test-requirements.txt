# `pypdf>=4.0` was never true: measured per release, the pdf suite fails on 4.3.1 (pypdf 4.x
# hands back raw UTF-16 bytes instead of decoded metadata strings, and --clear-meta crashes)
# and passes from 5.0.0 on -- there is no release between the two, so 5.0 is the exact floor.

#   2026-09-09. Treat them as untested until someone runs the suite against each one.

# shipped, which is the point. Pin only when a release flips a gate with no code change --
